# Reporting a security issue

Use the repository's private vulnerability reporting channel or contact the maintainer privately. Include the affected version and the operation that failed. Redact keys, headers and responses.

Market Mood needs a market-data key pair. The desktop reads environment variables first, then Windows Credential Manager or Linux Secret Service. The Settings screen writes the pair to the platform vault. Cached files contain historical prices and derived readings. They live in the current user's cache directory. Treat imported CSVs and cache files as local, trusted inputs. FFmpeg must come from a trusted installation on PATH.

If a credential is exposed, revoke it in the Alpaca dashboard, generate a replacement, and update the environment or vault. Rotation comes first. To purge a committed file, coordinate with collaborators, back up the repository privately, then use a fresh mirror clone and `git filter-repo --sensitive-data-removal --invert-paths --path PATH-TO-LEAK`. For inline tokens, use its `--replace-text` facility with a private replacement file. Review every affected ref before a coordinated force-push. Remove affected releases and CI artifacts, request host-side cached-ref removal, and have collaborators re-clone. Secret scanning cannot prove that every possible credential is absent.
